# Fresh Farms

Welcome to **Fresh Farms**, a premium e-commerce platform dedicated to bringing fresh, organic vegetables and fruits directly from the farm to your table. This project features a modern, responsive design with a focus on user experience and visual appeal.

## 🌿 About the Project

Fresh Farms is designed to showcase the quality and freshness of organic produce. The website includes:

- **Hero Section**: Captivating visuals to welcome visitors.
- **Product Listing**: A clean grid layout displaying available produce with prices.
- **Farm Story**: An "About Us" section highlighting sustainable farming practices.
- **Contact**: Easy-to-use contact form and location information.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop devices.

## 🛠️ Tech Stack

This project is built using modern web technologies:

- **[React](https://react.dev/)**: JavaScript library for building user interfaces.
- **[Vite](https://vitejs.dev/)**: Next-generation frontend tooling for fast builds.
- **[Tailwind CSS v4](https://tailwindcss.com/)**: Utility-first CSS framework for styling.
- **[Lucide React](https://lucide.dev/)**: Beautiful, consistent icons.
- **TypeScript**: For type-safe code.

## 🚀 Getting Started

Follow these instructions to set up and run the project on your local machine.

### Prerequisites

Make sure you have **Node.js** (version 20 or higher recommended) installed on your system.

### Installation

1.  **Clone the repository** (if you haven't already):

    ```bash
    git clone https://github.com/Annapurna-farms/Fresh-Farms.git
    ```

2.  **Navigate to the project directory**:
    The actual application code is located in the `Fresh_Farms` subdirectory.

    ```bash
    cd Fresh_Farms/Fresh_Farms
    ```

3.  **Install dependencies**:
    ```bash
    npm install
    ```

### 🏃‍♂️ Running the Application

To start the development server:

```bash
npm run dev
```

Open your browser and visit the URL shown in the terminal (usually `http://localhost:5173`).

### 📦 Building for Production

To create a production-ready build:

```bash
npm run build
```

The built files will be generated in the `dist` folder.
